## 🔧 Если возникли проблемы

### Ошибка: "ModuleNotFoundError: No module named 'qasync'"

```bash
pip install qasync
```

### Ошибка: "RuntimeError: Cannot enter into task"

Убедитесь, что используете обновлённый `main.py` и `event_bus.py`.

### Окно не открывается

Проверьте, что PyQt6 установлен:
```bash
pip install PyQt6
```
